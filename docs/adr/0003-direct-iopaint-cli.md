# Run IOPaint directly for each cleanup

The application invokes `iopaint run --model=MODEL --device=DEVICE --image INPUT --mask MASK --output OUTPUT` once per cleanup instead of managing a persistent HTTP server. Runtime Settings keep only the executable, model, device, and operation timeout; none are stored in `project.json`. Selected-block cleanup runs one process, while page cleanup remains sequential so progress, cancellation, and per-block error isolation use the existing worker flow. Cancellation or timeout terminates the active child process. A failed command, missing or invalid output, or wrong output dimensions preserves the existing cleanup and reports the error without silently choosing another cleanup method. This supersedes ADR 0001 and removes server readiness, port selection, and app-exit process ownership from the application.
